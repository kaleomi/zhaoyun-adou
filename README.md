# 赵云与阿斗

> 长坂坡上贼兵四起。征兵、排兵布阵、把相同的字叠在一起合成升级——护住阿斗头顶的三颗心。

竖屏网页**文字塔防对战**，手机和电脑都能玩。纯静态 HTML/CSS/JS，没有任何构建步骤，也不依赖服务器。

## 玩法

- **对战**：上下两个半场，你和对手各守一个阿斗。贼兵沿着红色箭头出发，走到阿斗跟前他就掉一颗心（Boss 掉两颗）。先把对手的心打光的一方获胜。
- **征兵**：花馒头一次招来 5 个字放进「营」里；再征一次会把没用掉的全换掉，价格每次上涨。打死贼兵、每波开始都会得馒头。
- **排兵布阵**：把字拖到白色营地上。拖动时显示射程圈——刀、骑只能打身边一圈，枪远一点，弓最远。场上的兵可以随时拖动换位，拖回「营」能换回一些馒头。
- **合成**：两个相同等级的相同的字叠在一起升一级（最高 7 级）。**武将**由名字的两个字拼成：「赵」+「云」= 赵云，再拼上名字里的字还能继续升星。
- **15 名武将**：赵云、张飞、关羽、刘备、黄忠、马超、许褚、典韦、曹操、孔明、吕布、周瑜、尚香、甄宓、貂蝉，各有技能；随段位解锁，后几位要靠击败对应的 Boss 收集将魂。
- **46 件兵器**：弓、枪、刀、剑四类，分普通到传说五个品质，很多带特效（落日弓、丈八蛇矛、青龙偃月刀、方天画戟、轩辕剑……），部分是武将专属。碎片合成、升星，再给武将装上。
- **6 种贼兵、7 个 Boss**：寇快、匪厚、甲穿重甲、巫会回血、盗揣着馒头；华雄斩将定身、张角放黑云、董卓锁链回血、吕布无视控制冲锋……
- **战场道具**：铲（挖新营地）、晋升令、砚台（换兵种）、地雷、战鼓、续命丹。
- **段位**：军士 → 校尉 → 少将 → 中将 → 上将 → 大将 → 都督 → 诸侯 → 霸主 → 君主 → 大帝，四张战场地图（巨鹿、云梦泽、虎牢关、赤壁）。
- **字阵羁绊**：相邻的字连成词有加成——刀枪、弓骑、枪骑、屯田；三个同种兵连成一线是长蛇阵，刀枪弓骑围成田字是四象阵。武将也有羁绊：桃园结义、五虎上将、三顾茅庐、连环计、虎卫、孙刘联姻、既生瑜、铜雀春深。场上会画出连线和名字。
- **锦囊**：每局带两个，战斗中各发动一次：空城计、火攻、草船借箭、苦肉计、借刀杀人（把贼兵丢给对手）、调虎离山、连环计、暗度陈仓。对手 AI 也会用。
- **天气与随机事件**：大雾、东风、暴雨、夜袭、酷暑，每种都改变打法；每隔几波还有天降粮草、流民投军、疫病流行等事件。
- **长坂坡战役**：九回故事关卡（桃园结义 → 七进七出），每回规矩不同，三星评价，通关送锦囊和将魂。
- **每日挑战**：每天北京时间 0 点换题，所有人同一张图、同一套武将兵器、同一种天气，比分数上全球排行。
- **无尽守城**：一个人守到撑不住为止，挑战最高波数。
- **存档码**：设置里可以导出 / 导入存档码，换手机或清缓存也能恢复进度。

电脑上：鼠标拖动 · 空格 征兵 · 1~5 选营里的兵 · Q/E 锦囊 · F 倍速 · Esc 暂停。宽屏两侧会显示对手阵容、下一波敌情和羁绊。手机上也可以“点一下选中，再点目标格子”，长按看详情，点顶部波次看敌情。

## 运行

- **本地**：直接双击 `index.html` 就能玩（所有脚本都是普通 `<script>`）。用 `file://` 打开时毛笔字体可能加载不了，会退回系统楷体；用任意静态服务器打开就正常。
- **存档**：自动保存在浏览器 localStorage。
- **手机**：可以“添加到主屏幕”，像 App 一样全屏打开（自带 manifest 与离线缓存）。

## 部署到 Cloudflare Pages

1. Cloudflare 控制台 → Workers & Pages → 创建 → Pages → 连接到 Git，选择本仓库。
2. 框架预设：`None`；构建命令：留空；构建输出目录：`/`。
3. 保存并部署。之后每次推送到主分支都会自动更新。

`_headers` 已设置好缓存策略，更新后玩家刷新就能拿到新版本。

### 开通每日挑战的全球排行榜（可选，免费）

排行榜用的是 Cloudflare Pages Functions（`functions/api/scores.js`，会随部署自动生效）+ 一个 KV 存储。不开的话游戏照常能玩，每日挑战的成绩只存在本机。

1. Cloudflare 控制台 → **Storage & Databases → KV** → **Create a namespace**，名字随便填，比如 `zhaoyun-adou-scores`
2. 打开这个 Pages 项目 → **Settings → Bindings**（旧界面在 Settings → Functions → KV namespace bindings）→ **Add → KV namespace**
   - Variable name 填 **`SCORES`**（必须一模一样）
   - KV namespace 选刚才建的那个
3. 回到 **Deployments**，对最新一次部署点 **Retry deployment**（绑定要重新部署才生效）

验证：打开 `https://你的域名/api/scores?board=today`，看到 `{"board":"d2026…","list":[]…}` 就是通了；看到 `no-kv` 说明绑定没生效。

免费版 KV 每天 1000 次写入，每次上传成绩最多写 2 次，小规模够用。成绩只做了基本校验，挡不住专门作弊的人。

## 目录

```
index.html            入口
css/style.css         样式
js/data.js            数据表：段位、地图、兵种、武将、兵器、贼兵、Boss、道具
js/battle.js          战斗模拟（纯逻辑，不碰 DOM，node 里也能跑）
js/ai.js              对手 AI（四档难度，和玩家用同一套操作接口）
js/view.js            战场绘制与拖放操作（Canvas）
js/ui.js              主城、匹配、武将、兵器、军需、段位、结算
js/audio.js           WebAudio 实时合成的音效与配乐
js/save.js            存档与养成（含存档码、战役进度、每日挑战记录）
js/net.js             排行榜接口调用
functions/api/scores.js  排行榜接口（Cloudflare Pages Function + KV）
fonts/brush.woff2     马善政毛笔楷书的子集（SIL OFL，见 fonts/OFL.txt）
tools/sim.js          无头对战模拟：node tools/sim.js 20 0 3 1
tools/power.js        比较不同养成程度能在无尽模式撑几波
tools/fuzz.js         所有武将 × 兵器组合各打一局，查报错
tools/campaign.js     战役每关用 AI 打几遍，看通关率
tools/subset_font.py  改了文字后重新裁剪字体：python3 tools/subset_font.py MaShanZheng-Regular.ttf
```

美术全部由代码绘制（汉字、水墨、地图都是 Canvas 现画），音效由 WebAudio 实时合成，仓库里没有图片和音频素材（图标除外）。
